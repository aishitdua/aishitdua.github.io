ghlake

An hourly lakehouse over GH Archive, the public record of every GitHub event. Idempotent ingest with size and gzip-CRC checks, a DuckDB silver layer with one row per event, and incremental dbt gold models that recompute only the days touched, guarded by grain, not-null, and freshness tests.

It runs itself on GitHub Actions and costs nothing. The Hugging Face dataset doubles as the warehouse, and the dashboard runs DuckDB-WASM in your browser against the gold Parquet files.
